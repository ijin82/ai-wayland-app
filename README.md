> "Автономный клиент" для голосового помощника и нейросети **Яндекс Алиса** на базе Яндекс Браузера без фонового агента с  интеграцией в GNOME и Wayland.

---

## 📌 Зачем это может быть нужно?

У Яндекса нет официального отдельного десктопного приложения «Алиса» для Linux: пользователям предлагается либо держать открытую вкладку в браузере, либо ставить фоновый Яндекс Агент.

**Alice-YB** решает эту задачу через запуск веб-версии ([ya.ru/alice](https://ya.ru/alice)) в режиме изолированного веб-приложения (`--app`) через уже установленный в системе **Яндекс Браузер**, создавая ощущение полноценной нативной программы:

* 🪟 **Отдельное окно приложения** — без адресной строки, вкладок, панелей расширений и другого визуального шума браузера.
* 🛡️ **Изолированный профиль** (`~/.config/alice-app`) — история, кэш и авторизация в Яндексе живут отдельно и не смешиваются с вашим основным браузером.
* 🚀 **Без фонового агента и демонов** — приложение не висит в трее и не расходует оперативную память и процессорное время после закрытия окна.
* 🐧 **Нативная интеграция с GNOME и Wayland**:
  * Корректно отображается оригинальная иконка Алисы в доке (**Dash to Dock**, **Ubuntu Dock**, **Dash**).
  * Решена проблема Wayland с сопоставлением окон (окно не теряет ярлык и не заменяется на дефолтную шестерёнку `application-x-executable`).
  * Приложение можно закрепить в «Избранное» (Pin to Dash) и переключаться через `Alt+Tab` как с любой другой программой.

---

## ⚙️ Системные требования

* **ОС:** Linux (протестировано на ALT Linux, Fedora, Ubuntu и др.)
* **Окружение рабочего стола:** GNOME 40+ под управлением **Wayland** *(под X11 из коробки не работает — см. раздел ниже)*
* **Браузер:** Установленный [Яндекс Браузер](https://browser.yandex.ru/linux/) (`yandex-browser` / `yandex-browser-stable`)

## 🚀 Установка

1. Склонируйте репозиторий (или скачайте архив):

   ```bash
   git clone https://github.com/ijin82/alice-wayland-app.git
   cd alice-wayland-app
   ```

2. Запустите скрипт установки:

   ```bash
   ./install.sh
   ```

Скрипт автоматически:

* Сделает скрипт запуска `alice-window.sh` исполняемым;
* Пропишет актуальный абсолютный путь в файл ярлыка `.desktop`;
* Скопирует ярлык в `~/.local/share/applications/`;
* Установит иконку `alice_512.png` и создаст симлинк для Wayland `app_id` в `~/.local/share/icons/hicolor/512x512/apps/`;
* Обновит кэш иконок и базы приложений рабочего стола.

После этого ярлык **«Алиса»** появится в списке приложений GNOME и поиске.

---

## 🖥️ Использование

* **Запуск из меню:** Откройте обзор приложений GNOME (`Super` / `Win`) и найдите **«Алиса»**.
* **Закрепление в доке:** Правый клик по иконке в доке → **«Добавить в избранное»**.

При первом запуске авторизуйтесь в вашем Яндекс ID — сессия сохранится в изолированном каталоге профиля.

---

## 🛠️ Настройка

Параметры запуска настраиваются в файле `~/.bin/alice-window.sh`:

### 1. Полноэкранный режим (Kiosk / Smart Display)

Если вы хотите использовать Алису на отдельном мониторе или в полноэкранном режиме, раскомментируйте или добавьте флаг:

```bash
FS_FLAG="--start-fullscreen"
```

### 2. Расположение профиля

По умолчанию данные сессии хранятся в:

```bash
PROFILE_DIR="$HOME/.config/alice-app"
```

При необходимости директорию можно изменить (например, если требуется несколько независимых профилей).

## 🧩 Технические подробности (Wayland & GNOME)

В сессиях Wayland композитор Mutter сопоставляет окна с ярлыками рабочего стола через свойство `app_id`. Chromium при запуске с флагом `--app=https://ya.ru/alice` генерирует идентификатор вида:

```text
chrome-ya.ru__alice-Default
```

Традиционный флаг `--class` в среде Wayland игнорируется. Чтобы док GNOME (Dash to Dock) корректно группировал окна и отображал иконку Алисы вместо дефолтной иконки-шестерёнки:

* В `alice-app.desktop` задан параметр `StartupWMClass=chrome-ya.ru__alice-Default`;
* В `install.sh` создаётся псевдоним иконки с соответствующим идентификатором приложения.

## ⚠️ Почему это не будет работать в X11 (Xorg) и как адаптировать?

Текущая конфигурация «из коробки» **рассчитана исключительно на сессию Wayland**. Если запустить её в X11, окно не сможет связаться с ярлыком: в доке снова появится шестерёнка либо окно объединится в одну группу с обычным Яндекс Браузером.

### В чём разница

* В **Wayland** сопоставление выполняется по `app_id`. Chromium при запуске `--app` жестко задает его в виде `chrome-ya.ru__alice-Default`.
* В **X11 (Xorg)** оконный менеджер сопоставляет окна по свойству `WM_CLASS`, которое состоит из двух значений `(instance, class)`:
  * По умолчанию Chromium в X11 генерирует `WM_CLASS`:
    `"ya.ru__alice", "Yandex-browser"` (без префикса `chrome-` и суффикса `-Default`).
  * Из-за этого значение `StartupWMClass=chrome-ya.ru__alice-Default` в X11 не совпадает, и среда считает окно частью основного браузера или неизвестным приложением.

### Что теоретически нужно исправить для X11

1. **В файле `alice-app.desktop`:**
   Изменить `StartupWMClass` на класс окна X11:

   ```ini
   StartupWMClass=AliceApp
   ```

   *(либо `StartupWMClass=ya.ru__alice`, если запуск производится без флага `--class`)*.

2. **В файле `alice-window.sh`:**
   Указать желаемый класс окна (под X11 Chromium реагирует на флаг `--class`):

   ```bash
   APP_CLASS="AliceApp"
   ```

3. **Обновить кэш ярлыков:**

   ```bash
   update-desktop-database ~/.local/share/applications/
   ```

*(Узнать точный класс любого открытого окна в X11 можно командой `xprop WM_CLASS`, кликнув затем по окну приложения).*

## 🗑️ Удаление

Чтобы удалить ярлык и иконку из системы:

```bash
rm -f ~/.bin/ai-window.sh ~/.bin/alice-window.sh
rm -f ~/.local/share/applications/alice-app.desktop ~/.local/share/applications/gigachat-app.desktop
rm -f ~/.local/share/icons/hicolor/512x512/apps/alice_512.png ~/.local/share/icons/hicolor/512x512/apps/gigachat_512.png
rm -f ~/.local/share/icons/hicolor/512x512/apps/chrome-ya.ru__alice-Default.png ~/.local/share/icons/hicolor/512x512/apps/chrome-giga.chat__-Default.png
gtk-update-icon-cache -f -t ~/.local/share/icons/hicolor 2>/dev/null || true
update-desktop-database ~/.local/share/applications 2>/dev/null || true
```

‼️ Если хотите также удалить сохранённые профили и кэш:

```bash
rm -rf ~/.config/alice-app ~/.config/gigachat-app
```
